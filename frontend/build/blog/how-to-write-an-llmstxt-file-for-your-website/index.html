How to Write an llms.txt File for Your Website

An llms.txt file is a simple text file on your website that gives AI tools useful information about your site and helps them understand what your business is about.

What Is llms.txt?

It is a small text file that gives AI tools a quick overview of your business and points them to the pages that matter most. You can use it to highlight important pages such as your services, pricing, contact page, or other useful information.

llms.txt is still a newer idea. It is not an official requirement that every website must follow.

Does it guarantee results? No. Having an llms.txt file will not automatically improve your rankings or make ChatGPT, Gemini, or other AI tools mention your business. AI tools use many different sources and factors when generating answers. Think of llms.txt as an additional way to make your website information easier to understand.

Why Do Websites Use It?

Businesses may choose to add an llms.txt file for a few simple reasons:

  • Gives AI tools a clear summary of the website
  • Points to important pages such as services and pricing
  • Makes key business information easier to find
  • Helps keep important pages clearly organized
  • Prepares the website for the growing use of AI search

It is a small addition to a website, but it can give AI systems another clear source of information about your business.

What Should Be in the File?

The file does not need to be long or complicated. A basic llms.txt file can include your business name, a short description, and links to important pages.

For example, you might include links to:

  • Main services
  • Pricing
  • About page
  • Contact page
  • Important guides or resources

The information should be simple, accurate, and easy for machines to read. There is no need to fill the file with long marketing messages or unnecessary information.

Where Does the File Go?

The llms.txt file should be placed in the main folder of your website rather than inside another folder. It is also important to remember that llms.txt is a newer setup option and is not the same as established files such as robots.txt or a sitemap.

What Goes Into Setting It Up?

Setting up the file involves a few simple steps: writing the content, choosing the right pages, uploading the file correctly, and checking that it works.

Choosing the pages is important because you do not need to include every page on your website. Focus on the pages that give useful information about your business, services, products, or pricing.

After creating the file, it also needs to be uploaded to the correct location and checked to make sure it can be accessed properly. If one of these steps is done incorrectly, the file may not work as expected even if it exists on your website.

Common Mistakes and Things Worth Rechecking

A few problems can come up when setting up llms.txt:

  • Uploading it to the wrong folder
  • Using broken or outdated links
  • Adding too much sales-focused content
  • Including pages that are no longer available
  • Thinking it replaces robots.txt or a sitemap
  • Forgetting to update it when the website changes

For example, if you remove a service page from your website but leave its old link in llms.txt, the file can become outdated. The same can happen when pages are renamed or moved.

Problems People Run Into Doing This Manually

The file itself is simple, but managing it manually can take more time as a website grows.

First, it may not always be obvious which pages should be included. A small website might have only a few important pages, while a larger website may have many services, resources, and landing pages.

Different website platforms can also have different ways of uploading files. A process that works on one platform may not work in exactly the same way on another.

Another issue is checking whether the file is actually accessible. It may look like the file has been uploaded, but there can still be problems with its location or setup.

Finally, there is no automatic reminder to update the file whenever your website changes. This means someone needs to remember to check it from time to time.
